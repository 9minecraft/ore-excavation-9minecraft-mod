# Ore Excavation — Mine Ores and Chop Trees in a Single Swing

Ore Excavation 9minecraft Mod lets you break entire ore veins and chop down whole trees in just one hit. You hold down a single button while mining, and every connected block pops out at once. This saves you a lot of time when clearing out large mines or gathering wood. It works just like normal mining, so your tools still take damage for every block broken, and enchantments like Silk Touch still work perfectly.

Mines all connected blocks of the same type when you hold the assigned key.

## What this build is

An unofficial rebuild of **Funwayguy**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
